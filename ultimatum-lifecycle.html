Ultimatum Triggers

Set up how your countdown campaigns start for each user, and what fires when someone's countdown ends without converting.

ⓘ

Triggers are for Evergreen campaigns. Fixed-date and Recurring campaigns run on a shared clock, so they have no per-user start or expiry to attach actions to. We surface them on this dashboard for visibility, but the trigger setup is greyed out for those types — open one to see why.

        Triggers are for Evergreen campaigns only

        This campaign runs on a shared clock — when the deadline arrives, it arrives for everyone simultaneously. There's no per-user start moment to wire a trigger source to, and no per-user expiry moment to fire actions on.

        If you need follow-up actions when this campaign ends, segment non-buyers in your email marketing tool — it's the natural home for "people who saw this and didn't buy" workflows.

        Want to use Triggers with this campaign? Switch its type to Evergreen in Campaign Settings. That gives each user their own personal countdown, which Triggers can attach to.
