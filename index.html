Feature 1 · P0

[Apprentice] Incoming Webhook Endpoints

Replaces Recipes #1 / #2 / #6 · 6,801 uses

Native webhook receiver inside Thrive Apprentice. External systems (ThriveCart, Stripe, SamCart, any CRM) POST a payload to a generated URL; Apprentice finds-or-creates the user and grants or revokes access.

  • Listening window with live payload capture
  • Smart auto-match: Email / First Name / Last Name
  • Shared Secret & HMAC security, default-on
  • Live logs with replay

Feature 2 · P0

[Architect] Form → Thrive Action

Replaces Recipe #10 · 363 uses

A fourth tab in the Architect / Leads form editor's Connection panel. On submit, fires a native Thrive action — Grant / Revoke Apprentice access, Start / Stop Ultimatum, Record Optimize conversion, and more.

  • Six actions across five Thrive plugins
  • Paired sub-operations (Grant / Revoke, Start / Stop)
  • Optional condition with IF / THEN labels
  • Optional timing: fire immediately or after a delay
  • Side-effect-free test drawer
